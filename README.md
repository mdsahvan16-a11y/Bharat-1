# Bharat Dairy (भारत डेरी) - Complete Flutter Android Application

## Build APK Command
```bash
flutter pub get
flutter build apk --release
```
The APK will be generated at `build/app/outputs/flutter-apk/app-release.apk`.

## Environment Notice
The current web runtime environment provides the full React + TypeScript offline PWA counter application with local database and Web Bluetooth printing. The Flutter source code is provided in this archive for building the native Android APK.
